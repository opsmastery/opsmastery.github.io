# OpsMastery brand

The mark is four bars rising to a peak, with a trace line over their tops and a dashed threshold. The bars and threshold come from tvt; the colors and the peak come from the OpsMastery Summit logo.

| File | Use |
| --- | --- |
| `opsmastery-mark.svg`, `opsmastery-mark-512.png` | The mark on its navy tile. Favicons, app icons, social images. |
| `opsmastery-avatar.svg`, `opsmastery-avatar-500.png` | Square, full-bleed version for the GitHub org avatar and other round or rounded crops. |
| `opsmastery-mark-plain.svg` | The mark without a tile, for dark backgrounds. |
| `opsmastery-mark-plain-light.svg` | The mark without a tile, deeper colors for light backgrounds. |
| `opsmastery-logo-dark.svg`, `opsmastery-logo-light.svg` | Mark and "OpsMastery" wordmark, for dark and light backgrounds. |
| `opsmastery-labs-logo-dark.svg`, `opsmastery-labs-logo-light.svg` | Mark with "OpsMastery" over "Labs", matching the Summit lockup. |
| `favicon.svg` | Same as the mark. |

PNG files are 4x exports of the SVGs. The wordmark is Inter (SIL Open Font License) converted to outlines, so no font is needed to display it.

Colors: navy `#1F2A44`, cyan `#2DD4FF`, teal `#00C2A8`, violet `#8B5CF6`, indigo `#6E74E6`, threshold green `#73BF69`. Light versions use `#0EA5D9`, `#00A08A`, `#7C3AED`, `#5B5FD6`, `#37872D` and a navy trace line.
