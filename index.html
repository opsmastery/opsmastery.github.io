Tools

tvt

Telemetry Value Tracker

Finds the metrics, labels and logs you pay for but never query. It proposes safe cuts as pull requests you review, and it never changes anything on its own. Works with Grafana, Prometheus, Mimir, Loki and the OpenTelemetry Collector.
